# Как создать и подключить базу данных (Google Таблицы)

Расширение Snov.io получает данные об email-адресах по публичным URL-ссылкам. Самый простой способ создать такую базу данных и управлять ей — использовать Google Таблицы и опубликовать их в формате CSV.

Ниже приведено пошаговое руководство, как это настроить.

## Шаг 1: Подготовка данных
1. Откройте [Google Таблицы](https://docs.google.com/spreadsheets/) и создайте новый документ.
2. Вставьте ваши email-адреса в один столбец (например, в столбец A).
3. **Важно:** Для лучшей производительности убедитесь, что в каждой ячейке находится только один email-адрес.

## Шаг 2: Публикация таблицы в интернете
Чтобы расширение могло считывать данные без авторизации, таблица должна быть публично доступной.
1. В верхнем меню Google Таблиц нажмите **Файл** (File).
2. Выберите **Поделиться** (Share) > **Опубликовать в интернете** (Publish to web).
3. В появившемся окне измените формат публикации с "Веб-страница" на **Значения, разделенные запятыми (.csv)**.
4. Нажмите кнопку **Опубликовать** (Publish) и подтвердите действие.

## Шаг 3: Получение ссылки CSV
1. После публикации Google Таблицы сгенерируют прямую ссылку.
2. Скопируйте эту ссылку. Обычно она заканчивается на `output=csv`.
3. *(Примечание: Расширению требуется, чтобы URL начинался с `http` или `https`).*

## Шаг 4: Подключение базы данных к расширению
1. Откройте окно (popup) расширения Snov.io в вашем браузере.
2. Вставьте скопированную ссылку CSV в одно из доступных полей (например, **CSV URL 1**).
3. Нажмите на палитру цветов рядом с полем, чтобы выбрать цвет подсветки для этого конкретного списка адресов.
4. Нажмите кнопку **Save Settings** (Сохранить настройки).
5. В конце нажмите **Fetch / Update Databases** (Загрузить / Обновить базы данных), чтобы загрузить email-адреса в локальное хранилище расширения.

### Возможные проблемы
* **Подсветка не появляется:** Убедитесь, что ваш URL-адрес корректен, публично доступен и возвращает текст, содержащий символы `@`.
* **Пустые списки:** Если указан неверный URL-адрес, расширение безопасно обработает его как пустой набор данных без сбоев. Просто исправьте ссылку и снова нажмите кнопку загрузки баз данных.
